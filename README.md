# **NETPRACTICE**


# Description

NetPractice introduces you to the basics of computer networking

The project involves solving multiple networking problems, where we have to change IP, Masks or routing tables of devices to correct the network and be able to communicate with the corresponding devices depending on the task.

# Resources

With NetPractice you learn about, TCP/IP addressing, subnet masks, default gateways, routers, switches, OSI layers, and more.

### TCP/IP addressing

TCP (Transmission control protocol) Defines the steps to make a connection with another device.

IP (Internet protocol) Provides a way to assign and identify addresses for networks, subnetworks, and hosts.

Resource: [TCP/IP addressing](https://www.ibm.com/docs/en/aix/7.2.0?topic=protocol-tcpip-addressing)

### Subnet masks

A subnet mask is basically what makes subnetting possible, its the subdivision of an ip network.

### Default gateways

Default gateways are usually used when the destination of a packet is outside of its local network, so the packet will be forwarded from the source to other networks.

Resource: [Default gateways](https://www.geeksforgeeks.org/computer-networks/default-gateway-in-networking/)

### Routers

Routers are able to forward packets to other networks.

### Switches

Switches allow multiple devices communicate on the same network.

### OSI layers

The OSI (Open Systems Interconnections) Model is a set of rules that explains how different computer systems communicate over a network. It's composed by 7 layers.

1. Physical layer.
2. Data link layer (DLL).
3. Network layer.
4. Transport layer.
5. Session layer.
6. Presentation layer.
7. Application layer.

Resource: [OSI Model](https://www.geeksforgeeks.org/computer-networks/open-systems-interconnection-model-osi/)
